# 快捷键

## macOS 截图

| 快捷键 | 功能 |
|---|---|
| `⌘⇧3` | 全屏截图 |
| `⌘⇧4` | 区域截图 |
| `⌘⇧5` | 截图工具栏（可选截图/录屏模式） |

> [!tip] `⌘⇧4` 松开鼠标即截图；`⌘⇧5` 需按 `Enter` 确认

## Tab 切换快捷键（已统一）

目标：所有常用 app 对齐到 `⌘⇧[` / `⌘⇧]`

| App | 快捷键 | 状态 |
|---|---|---|
| Arc, Chrome, VS Code, Ghostty | `⌘⇧[` / `⌘⇧]` | ✅ 默认 |
| Obsidian | `⌘⇧[` / `⌘⇧]` | ✅ sequence-hotkeys 插件 |
| Paseo | `⌘⇧[` / `⌘⇧]` | ✅ Karabiner 转发 → `⌥⇧[`/`⌥⇧]` |

### NuPhy Air96 V2-1

NuPhy 通过蓝牙连接时会被 Karabiner 识别为键盘与指针的复合设备。若 EventViewer 能看到按键、但规则不生效，需要在当前 Karabiner profile 的 `devices` 中为该设备明确设置 `"ignore": false`。设备地址可用 `karabiner_cli --list-connected-devices` 查询；重新配对后地址可能变化。

## 新建 Tab 快捷键（已统一）

目标：所有常用 app 对齐到 `⌘T`

| App | 快捷键 | 状态 |
|---|---|---|
| Arc, Chrome, Ghostty, Paseo | `⌘T` | ✅ 默认 |
| VS Code | `⌘T` | ✅ keybindings.json（原默认：Go to Symbol） |
| Obsidian | `⌘T` | ✅ sequence-hotkeys 插件 |

## 书签快捷键 `⌘D`

各 app 中 `⌘D` 的功能不同，仅浏览器和 Obsidian 用于书签：

| App | `⌘D` 功能 | 备注 |
|---|---|---|
| Arc, Chrome | 添加书签 | ✅ 默认 |
| Obsidian | 书签当前文件 | ✅ sequence-hotkeys 插件 |
| VS Code | 多光标选择下一个匹配 | 非书签功能，保留默认 |
| Ghostty | 分屏（split right） | 非书签功能，保留默认 |
| Paseo | 无书签功能 | — |
