# 快捷键

> [!info] 范围
> 本页是 Mac 上「全局 / 系统级」和「app-specific」快捷键的单一真相源。外接键盘自身的物理键位、层与宏单独记录在 [[外接键盘按键重映射]]。

## 全局 / 系统级映射

### 中英文输入源

| 按键 | 当前动作 | 所有者 / 权威源 |
|---|---|---|
| 快速连按两次左 `Control` | 在 U.S. 与简体中文拼音之间切换 | Input Source Pro 2.11.0；`~/Library/Application Support/Input Source Pro/Main.sqlite` |
| `⌥Space` | 在 U.S. 与简体中文拼音之间切换 | macOS symbolic hotkey `60`（已启用） |
| `Caps Lock` | 普通大写锁定，**不**切换输入源 | `NSGlobalDomain.TISRomanSwitchState = 0` |

- Input Source Pro 当前切换组 ID：`9C235DCD-00B3-402F-8726-7E2FD11E3A38`。
- 输入源 ID：U.S. 为 `com.apple.keylayout.US`；简体中文拼音为 `com.apple.inputmethod.SCIM.ITABC`。
- Input Source Pro 的 plist 中可能看不到映射；以 app 实时 UI 和 `Main.sqlite` 为准。
- 上述左 `Control` 双击是软件全局映射：MacBook 或外接键盘只要输出 `left_control`，都会被它识别。

### Typeless

| 按键 | 当前动作 |
|---|---|
| 左 `Option` | 按住说话（push-to-talk） |
| 左 `Option` + `Space` | 免按住说话（hands-free） |
| 左 `Option` + `Shift` | 翻译 |
| 左 `Control` + 左 `Command` | 听写模式 |
| 左 `Control` + `Command` + `V` | 粘贴上一条转录 |

当前权威源为 `~/Library/Application Support/Typeless/app-settings.json`。历史临时文件中出现过其他 Ctrl 方案，但那些不是当前生效配置。

> [!warning] 重叠按键
> Typeless 的左 `Option` + `Space` 与 macOS 的 `⌥Space` 是同一组物理按键。Typeless 运行时可能先捕获它；如果输入源切换表现不一致，先检查 Typeless 是否正在运行。

## 设备专属映射（与全局 / app-specific 分开）

- WAVE75 普通 `Caps Lock` 仅用于大写锁定。
- WAVE75 `Fn+Caps` 切换 Sayo Secure 层的持久状态。
- 按住 WAVE75 左或右 `Shift` 时，临时启用同一个 Sayo Secure 层。
- 详见 [[WAVE75 自定义映射]] 和 [[SayoDevice 2x3B 自定义映射]]。

## macOS 截图

| 快捷键 | 功能 |
|---|---|
| `⌘⇧3` | 全屏截图 |
| `⌘⇧4` | 区域截图 |
| `⌘⇧5` | 截图工具栏（可选截图/录屏模式） |

## Tab 切换快捷键（已统一）

目标：所有常用 app 对齐到 `⌘⇧[` / `⌘⇧]`

| App | 快捷键 | 状态 |
|---|---|---|
| Arc, Chrome, VS Code, Ghostty | `⌘⇧[` / `⌘⇧]` | ✅ 默认 |
| Obsidian | `⌘⇧[` / `⌘⇧]` | ✅ sequence-hotkeys 插件 |
| Paseo | `⌘⇧[` / `⌘⇧]` | ✅ Karabiner 转发 → `⌥⇧[`/`⌥⇧]` |

Paseo 的转发是 app-specific Karabiner 规则，仅在 bundle ID `sh.paseo.desktop` 为前台 app 时生效。左/右 `Command` × 左/右 `Shift` × 左/右方括号共八个 manipulator，因此任意一侧的修饰键组合都会被覆盖。另有两个 Paseo 兼容 manipulator，让 NuPhy 的物理 `⌥⇧[` / `⌥⇧]` 保持为同一输出，直接切换 tab。

### NuPhy Air96 V2-1

NuPhy 通过蓝牙连接时会被 Karabiner 识别为键盘与指针的复合设备。若 EventViewer 能看到按键、但规则不生效，需要在当前 Karabiner profile 的 `devices` 中为该设备明确设置 `"ignore": false`。设备地址可用 `karabiner_cli --list-connected-devices` 查询；重新配对后地址可能变化。

## 新建 Tab 快捷键（已统一）

目标：所有常用 app 对齐到 `⌘T`

| App | 快捷键 | 状态 |
|---|---|---|
| Arc, Chrome, Ghostty, Paseo | `⌘T` | ✅ 默认 |
| VS Code | `⌘T` | ✅ keybindings.json（原默认：Go to Symbol） |
| Obsidian | `⌘T` | ✅ sequence-hotkeys 插件 |

## 书签快捷键 `⌘D`

各 app 中 `⌘D` 的功能不同，仅浏览器和 Obsidian 用于书签：

| App | `⌘D` 功能 | 备注 |
|---|---|---|
| Arc, Chrome | 添加书签 | ✅ 默认 |
| Obsidian | 书签当前文件 | ✅ sequence-hotkeys 插件 |
| VS Code | 多光标选择下一个匹配 | 非书签功能，保留默认 |
| Ghostty | 分屏（split right） | 非书签功能，保留默认 |
| Paseo | 无书签功能 | — |
